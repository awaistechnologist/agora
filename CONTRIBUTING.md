# Contributing to Agora

Thank you for your interest in contributing to Agora!

## Getting Started

1.  Fork the repository.
2.  Clone your fork locally.
3.  Install dependencies: `./install.sh`.
4.  Create a branch for your feature or fix: `git checkout -b feature/my-new-feature`.

## Development Workflow

-   **Backend**: The Python backend is in `backend/`. Run with `./start.sh` (or `python run.py` inside `venv`).
-   **Frontend**: The React app is in `frontend/`. Use `npm run dev` inside `frontend/` for hot-reloading during development.

## Pull Requests

1.  Ensure your code follows the existing style.
2.  Test your changes locally.
3.  Submit a Pull Request to the `main` branch.
4.  Describe your changes clearly in the description.
